# CDCsite

Sito vetrina della mia attività di sviluppo siti web per piccole aziende.

**Live:** [cdcsite.vercel.app](https://cdcsite.vercel.app)

## Stack

- HTML/CSS/JS vanilla (no framework needed)
- Tailwind-like utility approach con CSS custom
- Google Fonts: Bricolage Grotesque, Geist, JetBrains Mono
- Hosting: Vercel
- Versioning: GitHub

## Deploy

Il sito si deploya automaticamente su Vercel ad ogni push sul branch `main`.

```bash
git add .
git commit -m "update"
git push
```

## Struttura

```
cdcsite/
├── index.html       # Single page application
├── vercel.json      # Config Vercel + headers di sicurezza
├── robots.txt       # SEO
└── README.md
```
